**The lines whose result is not the expected one, and why.** All are this network resetting SSH connections, or
mistakes in our own scripts, not the checks:

- `responder-check.sh`, `arm64-responder-refused-on-amd64`, `accepted` (twice): step 7's SSH failed three times with

  code was printed ("exit ?"). The Vendor's sshd logged the same connections as reset by this machine before
  authentication, so something on the path between the two resets new SSH connections when several come in a short
  time; the same step and message as on 2026-11-12 and 2026-11-16. Step 7's remote command was then run by hand on
  the Vendor: refused, exit 1, "att-ra-responder was built for GOARCH=arm64 but this instance is amd64". That is the
  first hand-written line (its `at` is approximate).

  hand-written line.
