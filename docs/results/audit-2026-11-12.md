## (b) The measurement hash

`keccak256( for each measurement, sorted by name: "<name>=<hex value>\n" )` is implemented in:

- `internal/chain/register/Vendor/register.go`, `MeasurementHash`
- `internal/chain/register/auditor/register.go`, `MeasurementHash` (also used by `chain/lookup/{Vendor,auditor}` and `core/compare/{Vendor,auditor}`)
- `internal/core/compare/user/compare.go`, `measurementHash`
- `internal/chain/lookup/user/ether/reader.go`, `measurementHash`

The four are textually identical. To check them on real values, each package now has `hash_golden_test.go` with the
same table: one recording per format, with the hash computed independently by Foundry's `cast keccak` (1.8.0) over
the same lines.

| format | values from | measurement hash |
|---|---|---|
| `aws-nitro` | `internal/tee/request/testdata/nitro-attestation.cbor` | `3d73c2f1…77a5` |
| `intel-tdx` | `internal/tee/parse/tdx/testdata/gcp-c3-opt2m-v1-quote.bin` | `dc9a25c0…cb5f` |
| `amd-sev-snp-initrd` | live evidence of the stock-boot SEV-SNP guest, 2026-11-12 | `2a571358…9957` |
| `amd-sev-snp-verity` | `internal/tee/parse/snp/testdata/gcp-n2d-opt2-v1-*` | `53477d04…5331` |

All four implementations and `cast` agree on all four. The name order is Go's byte order, so `PCR12` sorts before
`PCR4`; `cast` was given the lines in that order and agreed, so the order is not a hidden assumption.

## (c) The commands the docs give

1. Every `--flag` written next to an `att-*` command in `*.md`, `*.sh` and `*.go` was looked up in the flag
   definitions of `cmd/`. The only unknown ones were nitro-cli's (`--all`, `--debug-mode`, `--enclave-cid`).
2. Each `att-<role> <subcommand> … --flag` was checked against that subcommand's own `-h` output, with binaries built
   from this commit. No flag is given to a subcommand that does not accept it.
3. Phrases the docs quote from the output (`✓ matches`, `nobody has registered`, `Registry deployed at`, `build env
   matches`, `every PCR is zero`) exist in the code.

was available. *(A pointer to the work log was removed here on 2026-11-16, `544dfe5`.)*
